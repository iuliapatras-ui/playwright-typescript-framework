# Playwright + TypeScript Test Automation Framework

UI and API test automation for the [Practice Software Testing Toolshop](https://practicesoftwaretesting.com),
a demo web shop built for testers, written with [Playwright Test](https://playwright.dev) and TypeScript.

> Work in progress: the README is completed once the framework is in place.

## Quick start

```bash
npm ci
npx playwright install --with-deps
npm test
```
